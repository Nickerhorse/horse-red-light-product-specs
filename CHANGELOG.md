# Changelog

## v1.0.0 — 2026-11

Initial public release of the data package:

- Main published-specification table: 11 product rows.
- Separate supplementary table: 3 product rows for contradiction checks, outside the main denominator.
- AI answer audit: 36 records, including overlapping detail and summary rows and measures with different scopes.
- Evidence register: 61 source records spanning research, reviews, and guidance.
- Separate Zenodo and GitHub descriptions, a complete column dictionary, method and limitations, citation metadata, and a CC BY 4.0 license reference.

This is the first public release of the dataset. Audit corrections to the T2, T3 and supplementary tables were applied before release. The archive DOI for this version is 10.5281/zenodo.24352070.
